# Neverlose-style Windows Control Center (.exe)

Десктопный прототип на `tkinter` в стиле dark/neverlose с компактными карточками и переключателями ON/OFF.

## Что сделано

- уменьшенные карточки функций;
- меню в neverlose-like стиле (тёмная палитра + фиолетовый акцент);
- анимированные тумблеры ON/OFF;
- набор реальных системных твиков через реестр с проверкой состояния при запуске.

## Реестровые функции в разделе System Tweaks

- Отключить все уведомления Windows;
- Отключить уведомления на lock screen;
- Отключить рекламный ID;
- Отключить советы Windows;
- Отключить рекомендации в меню Пуск;
- Отключить activity history.

Каждый переключатель:
1. читает состояние из реестра при отрисовке;
2. записывает значение в реестр при переключении;
3. повторно проверяет запись и только затем подтверждает новое состояние.

> Важно: реестровые функции работают только на Windows.

## Запуск

```bash
python3 app.py
```

## Сборка `.exe` (Windows)

```powershell
pip install -r requirements.txt
pyinstaller --noconfirm --onefile --windowed --name ControlCenter app.py
```

Готовый файл:

```text
dist/ControlCenter.exe
```
